# 40 · 知识库问答清单（41 条）

> 来源：平台知识库的「QA 问答」批量导入文件。这些是检索命中率最高的标准问答。

| # | 问题 | 答案 |
|---|---|---|
| 1 | 阿尔奇公式里 a、m、n 一般取多少？ | a 为岩性系数，一般 0.6~1.5，常取 a=1；m 为胶结指数，变化范围 1.3~3，一般为 2 左右，常取 m=2；n 为饱和度指数，亲水岩石 1.5~2.5、常取 n=2，亲油岩石 n>2.5；b 为与岩性有关的系数，0.6~1，常取 b=1。以上为教材《岩石物理学基础》给出的取值范围。 |
| 2 | 砂岩的骨架时差是多少？ | 教材表 5-1 给出砂岩纵波时差 1250~222 μs/m（对应纵波速度 800~4500 m/s）。判断骨架时差时取该区间的低时差端（致密端），常用 222 μs/m，对应纵波速度 4500 m/s；而疏松砂岩的时差可高至 1250 μs/m。 |
| 3 | 阿尔奇公式有什么适用条件？ | 阿尔奇公式仅适用于骨架不导电的、孔隙性纯岩石或泥质含量很少的岩石。其中 a、b、m、n 这几个参数影响因素众多，目前还不能准确地阐述其地质意义。实际油气储层评价中，应针对特定地层开展岩石电阻率测量，建立本区的岩电关系，不能无条件套用通用取值。 |
| 4 | 地层水电阻率 R_w 能查表直接得到吗？ | 不能。R_w 不是普适常量，而是本井本区的值。获取途径有三种：一是水分析资料实测，最准确；二是由矿化度加温度估算，用教材表 4-3 与图 4-5，这是没有实测资料时的标准途径；三是由自然电位 SP 曲线反算。 |
| 5 | 教材表 4-3 给出的 NaCl 溶液电阻率是多少？ | 在 18℃ 下：浓度 10 mg/L 时电阻率 536.0 Ω·m；浓度 100 mg/L 时 54.6 Ω·m；浓度 1000 mg/L 时 5.75 Ω·m。同表还给出 KCl（573.0/58.2/5.75 Ω·m）与 MgCl₂（431.0/45.0/4.99 Ω·m）。 |
| 6 | 地层水电阻率与浓度、温度是什么关系？ | 浓度越高，溶液中离子数越多，导电能力越强，电阻率越低；温度升高时，盐类溶解度（电离度）增加、离子数增多，同时溶液黏度降低、离子迁移率增大，因此电阻率也降低。已知浓度、温度和电阻率中的两个值，即可求第三个。 |
| 7 | 声波时差 Δt 和波速 v 是什么关系？ | 二者互为倒数。教材原文：在声学理论中，波速的倒数（1/v）称为慢度，在地球物理测井领域中则习惯称为声波时差，或简称为时差。换算关系为 时差 = 1000000 / 波速，时差用 μs/m，波速用 m/s。 |
| 8 | 声波时差的 μs/m 和 μs/ft 怎么换算？ | 1 μs/ft = 3.28084 μs/m；1 μs/m = 0.3048 μs/ft。中文文献与教材多用 μs/m，英文与现场资料多用 μs/ft，两者相差约 3.28 倍，引用前必须先确认单位。自检方法：由时差反推速度 v = 1000000/Δt，砂岩骨架应约 5500 m/s；若算出 59000 m/s 这类数值，说明换算方向反了。 |
| 9 | 补偿中子测井为什么必须做岩性校正？ | 中子测井的读数是视石灰岩孔隙度 φCNP，仪器按纯水饱和石灰岩刻度。当地层岩性不是石灰岩时，读数不再等于真实孔隙度，因此必须做岩性校正。其物理基础是氢是最强的中子减速剂，读数主要反映地层含氢量。 |
| 10 | 什么是中子测井的挖掘效应？ | 气层的中子读数偏低、曲线呈下凹形态，这一现象称为挖掘效应。它是识别气层的关键标志，通常与密度曲线配合使用：当中子孔隙度小于密度孔隙度时，判断为含气。 |
| 11 | 致密白云岩为什么会出现负孔隙度？ | 这是刻度基准造成的计算假象，不是地下存在负孔隙。密度孔隙度公式为 φ_D = (ρ_ma − ρ_b)/(ρ_ma − ρ_f)，公式按石灰岩刻度基准建立；致密白云岩的骨架密度高于该基准，代入后得到负值。 |
| 12 | 天然伽马 GR 测井测的是什么？ | 测量地层中天然放射性元素钾 K、铀 U、钍 Th 衰变释放的 γ 射线强度，单位是 API，样板图横坐标范围为 0~150 API。泥岩因黏土矿物极易吸附铀钍钾而呈锯齿状高值；砂岩放射性物质含量低，曲线平稳低值。 |
| 13 | 为什么伽马曲线比电阻率曲线更不平滑（更锯齿状）？ | 因为伽马测量的纵向分辨率高于电阻率。黏土矿物、泥岩、页岩极易吸附铀钍钾，放射性含量显著偏高，在薄互层处表现为剧烈的锯齿状起伏。伽马曲线的纵向分辨率优势也是它常被用来划分薄层与岩性骨架的原因。 |
| 14 | 黑色页岩在伽马曲线上有什么特点？ | 黑色页岩因铀富集，伽马值极高，极易超量程。读图时遇到伽马极高的层段，除了泥岩还应考虑黑色页岩，注意区分。 |
| 15 | 自然电位 SP 测井的电动势来自哪里？ | 自然电位属电化学测井，产生的电动势来源分为两部分：扩散电动势与薄膜（吸附）电动势。在淡水泥浆体系下效果最好，当 R_w 大于 R_mf 时，砂岩段 SP 呈明显负偏移。 |
| 16 | 什么是自然电位曲线上的铁路轨效应？ | 铁路轨效应是 SP 曲线的一种强特征形态，用于识别渗透层。砂岩储层段 SP 呈明显负偏移，形态类似铁路轨道，是判断渗透性的重要标志。 |
| 17 | 井径曲线扩径可能是什么原因造成的？ | 扩径有三种常见成因：泥岩水化、盐岩溶解、煤层垮塌。井径的判读方法是将读数与钻头直径比较。另外，井径小于钻头直径（缩径）说明泥饼发育，指示渗透层。 |
| 18 | 深浅电阻率重合一定代表含油气吗？ | 不一定。致密灰岩的深浅电阻率也会高阻重合，原因是它没有孔隙、没有冲洗带、也没有侵入，这与含油气无关。而水层同样表现为深浅电阻率基本重合。因此深浅重合必须结合岩性、孔隙度与其他曲线综合判断。 |
| 19 | 油层在深浅电阻率上有什么特征？ | 油层表现为深电阻率大于浅电阻率，呈正幅度差。原因是深电阻率测原状地层，浅电阻率测冲洗带；油气被泥浆滤液驱替后，冲洗带电阻率低于原状地层。水层则是深浅电阻率基本重合。 |
| 20 | 什么是电阻率的侵入反向？ | 侵入反向指浅电阻率大于深电阻率的现象，由泥浆侵入导致。它属于四种典型地层电阻率响应之一，另外三种是水层深浅重合、油层正幅度差、致密灰岩高阻重合。 |
| 21 | 补偿密度测井的物理原理是什么？ | 补偿密度测井基于康普顿散射，由体积模型的质量守恒推导而来。密度孔隙度公式为 φ_D = (ρ_ma − ρ_b)/(ρ_ma − ρ_f)。常见骨架密度取值：砂岩 2.65、石灰岩 2.71、白云岩 2.87、硬石膏 2.96、石盐 2.03 g/cm³；孔隙流体淡水取 1.0 g/cm³。 |
| 22 | 中子与密度孔隙度交会怎么判断？ | 有四条判断口诀：两条曲线重合表示液烃或水；中子孔隙度 φCNP 小于密度孔隙度 φCFD 表示含气（中子偏低）；两条曲线同时抬升表示孔隙发育；两条曲线同为低值表示致密。 |
| 23 | 声波时差测井的孔隙度公式是什么？ | 使用 Wyllie 时间平均方程：Δt_log = (1−φ)×Δt_ma + φ×Δt_f。求解声波孔隙度得 φ_s = (Δt_log − Δt_ma)/(Δt_f − Δt_ma)，其中 Δt_log 为声波曲线读数，Δt_ma 为岩石骨架时差，Δt_f 为孔隙流体时差。 |
| 24 | 煤层在测井曲线上有什么特征？ | 煤层表现为低密度、高氢、低速三重标志：伽马中到高；SP 小幅偏移；中低阻；井径扩径垮塌；中子高；密度高；声波时差极高。需要特别注意：煤层的三高一低特征极易被误判为高孔隙砂岩。 |
| 25 | 盐岩（石盐）在测井曲线上有什么特征？ | 石盐表现为伽马极低；SP 曲线失真；高阻；严重扩径冲蚀；中子接近 0；密度偏高；声波时差低。因淡水泥浆会溶解盐岩导致井眼破坏，该层段多数测井数据失效，解释时应放弃使用。 |
| 26 | 硬石膏的测井响应是什么？ | 伽马低；SP 平直；高阻；井径规则；中子极低；密度极低、接近负孔隙；声波时差低。骨架密度为 2.96 g/cm³。 |
| 27 | 多孔含水砂岩储层的测井响应是什么？ | 伽马低值平稳；SP 明显负偏移并出现铁路轨效应；深浅低阻、几乎重合；井径缩小、泥饼发育；中子高；密度高且两条孔隙度接近；声波时差中等。整体表现为渗透性好。 |
| 28 | 多孔含油砂岩储层的测井响应是什么？ | 伽马低值平稳；SP 负偏移；深电阻大于浅电阻、呈正幅度差；泥饼发育；中子高；密度高且气层中子降低；声波时差中等。特殊现象是油水界面处电阻率断崖式下跌。 |
| 29 | 现场读图的完整步骤是什么？ | 共六步。第一步，用伽马与井径划分岩性骨架；第二步，用自然电位筛选渗透性储集层；第三步，用深浅电阻率交会判断流体性质；第四步，用中子-密度孔隙度组合识别孔隙发育与气层；第五步，用声波时差做辅助验证；第六步，综合多曲线交叉验证，排除假象。 |
| 30 | 测井解释有哪些常见读图陷阱？ | 共四个。第一，盐岩扩径导致曲线失真，应放弃该段的 SP 与电阻率解释；第二，白云岩出现负孔隙度是骨架密度效应造成的刻度基准问题，不是高孔隙；第三，煤层的三高一低特征极易误判为高孔隙砂岩；第四，致密灰岩深浅电阻率重合不等于含油气。 |
| 31 | 泥质含量的计算公式是什么？ | 先求伽马指数 IGR = (GR_log − GR_clean)/(GR_shale − GR_clean)，再求泥质含量。本课程采用的简化形式为 V_sh = 0.33×(2^(2×IGR)−1)。通式为 V_sh = (2^(GCUR×IGR)−1)/(2^GCUR−1)，其中 GCUR 为与地质年代有关的经验系数，古近系与新近系常取 3.7，老地层常取 2。 |
| 32 | GR_clean 和 GR_shale 应该取什么值？ | GR_clean 是纯砂岩（纯储层）的伽马值，GR_shale 是纯泥岩的伽马值。它们不是普适常量，而是本井本区的统计值，通常取大套泥岩段的最高值与大套砂岩段的最低值。没有实测资料时不得臆造。 |
| 33 | 什么是地层因素 F？ | 对同一块岩石样品，地层水电阻率与岩石电阻率之比为常数，这个比值定义为地层因素 F = R_o/R_w，其中 R_o 为 100% 含水岩石的电阻率，R_w 为地层水电阻率。经统计，F 与孔隙度 φ 的关系为 F = a/φ^m，合并后即阿尔奇第一公式。 |
| 34 | 什么是电阻增大系数 I？ | 对同一岩石，当含油饱和度相同时，R_t 与 R_o 之比为常数，这个比值定义为岩石电阻率增大系数 I，也称为地层电阻率指数，表达式为 I = R_t/R_o = b/(1−S_w)^n = b/S_o^n。这一关系称为阿尔奇第二公式。 |
| 35 | 黏土矿物在孔隙中有哪几种存在形式？ | 据 J.W. Neasham 研究有三种。离散式：黏土颗粒呈离散状态，高岭石常见此形式，不仅降低有效孔隙度，细小颗粒还会在孔隙中运移。内衬式：附着孔隙内壁形成连续薄膜（≤12 μm）黏土壳，形成大量微孔隙（≤2 μm）。搭桥式：由孔隙内壁向喉道发展形成搭桥，连接颗粒、造成更多微孔隙，使流体流动路径更曲折。 |
| 36 | 岩石电阻率在实验室怎么测量？ | 试样采用标准圆柱状或全直径岩心，标准圆柱体直径约 2.54 厘米，可测 x、y、z 三个方向电阻率以判别各向异性。方法可采用两极法或四极法。主要设备有游标卡尺、岩心夹持器、LCR 数字电桥仪，测量中一般采用 50 Hz 交流电。计算公式为 R = π×d²×V/(4×l×I)，其中 d 为岩心直径，l 为岩心长度，I 为通过岩心的电流，V 为岩心两端电位差。 |
| 37 | 改变岩心含水饱和度有哪些方法？ | 教材列出五种：驱替法、自吸增水法、风干法、离心法和半渗透隔板法。实验过程中需根据岩心的渗透性、地层水矿化度，以及地层含流体类型（油或气）的高低来选择方法。驱替法一般适用于渗透性较好的岩石，做法是先将岩心 100% 饱和水，再用原油或气在一定压力下驱出岩心中的水。 |
| 38 | 常见经验关系 Humble、Tixier、Shell 分别是什么？ | Humble 关系：F = 0.62×φ^(−2.15)，适用于颗粒状岩石或较软岩石（如砂岩）。Tixier 关系：F = 0.81×φ^(−2)，同样适用于颗粒状岩石或较软岩石。Shell 关系：F = φ^(−m)，其中 m = 1.87 + 0.019/φ，适用于无裂缝的碳酸盐岩（孔隙度小于 9%）。教材还指出，阿尔奇最初的 F = φ^(−2) 关系适用于多数种类的碳酸盐岩。 |
| 39 | 阿尔奇含水饱和度通式怎么写？ | S_w = ( a×b×R_w / ( R_t×φ^m ) )^(1/n)。式中 a、m 及 b、n 统称为岩电参数：a 为岩性系数，b 为与岩性有关的系数，m 为胶结指数，n 为饱和度指数，R_w 为地层水电阻率，R_t 为原状地层电阻率（深电阻率读数），φ 为有效孔隙度。 |
| 40 | 测井解释能直接判断某个层段是什么岩性吗？ | 不能。本知识库不含真实井的实测数据，只能回答测井曲线的原理、岩性响应的一般规律、读图方法与公式参数。要判断某个具体层段的岩性，需要该井的实测曲线与地质资料。另外，掌握等级与判分也不依赖本知识库。 |
| 41 | 地层温度怎么计算？ | 用经验公式 T = T₀ + G×H。其中 T₀ 为地面温度（℃），H 为地层埋深（m），G 为地温梯度（℃/100m），T 为所计算深度下的地层温度。计算地层水电阻率时需要用到的温度就是由此得到。 |

# K04 · 伽马曲线 GR 的衍生公式：泥质含量

> 所属考点：[[C01-伽马曲线]] ｜ 所在部分：第一部分　测井曲线响应与读图方法 ｜ 全文 384 字

## 知识原文

由伽马曲线可计算泥质含量。先求伽马指数（又称泥质指数）：

IGR = ( GR_log − GR_clean ) / ( GR_shale − GR_clean )

再求泥质含量，本课程采用的简化形式为：

V_sh = 0.33 × ( 2^( 2 × IGR ) − 1 )

通式为 V_sh = ( 2^( GCUR × IGR ) − 1 ) / ( 2^GCUR − 1 )，其中 GCUR 为与地质年代有关的经验系数，古近系与新近系常取 3.7，老地层常取 2。

式中符号含义：GR_log 为实测伽马值；GR_clean 为纯砂岩（纯储层）的伽马值；GR_shale 为纯泥岩的伽马值。

重要限制：GR_clean 与 GR_shale 不是普适常量，而是本井本区的统计值，通常取大套泥岩段的最高值与大套砂岩段的最低值。没有实测资料时不得臆造。

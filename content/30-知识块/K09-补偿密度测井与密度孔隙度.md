# K09 · 补偿密度测井与密度孔隙度

> 所属考点：[[C06-密度孔隙度]] ｜ 所在部分：第一部分　测井曲线响应与读图方法 ｜ 全文 288 字

## 知识原文

补偿密度测井的物理原理是康普顿散射，由体积模型的质量守恒推导而来。

密度孔隙度公式：φ_D = ( ρ_ma − ρ_b ) / ( ρ_ma − ρ_f )

式中符号含义：ρ_ma 为岩石骨架密度；ρ_b 为地层体积密度（密度测井读数）；ρ_f 为孔隙流体密度。

五类常见骨架密度取值：砂岩 2.65、石灰岩 2.71、白云岩 2.87、硬石膏 2.96、石盐 2.03，单位均为 g/cm³。孔隙流体密度淡水取 1.0 g/cm³。

负孔隙度假象：致密白云岩因骨架密度高于灰岩刻度基准，会读出负值。这不是地下存在负孔隙，而是刻度基准与实际岩性不一致造成的计算假象。

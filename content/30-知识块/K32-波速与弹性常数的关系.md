# K32 · 波速与弹性常数的关系

> 所属考点：[[C07-声波时差]] ｜ 所在部分：第三部分　声波速度与时差参数表 ｜ 全文 291 字

## 知识原文

纵波速度与横波速度的表达式：

v_p = 根号( ( λ + 2G ) / ρ_b )

v_s = 根号( G / ρ_b )

拉梅常数表达式：λ = 2Gν / ( 1 − 2ν )。若泊松比 ν 等于 0.25，则 λ 等于 G，于是 v_p = 根号3 × v_s。

式中 ρ_b 为密度（单位 g/cm³），λ 为拉梅常数，G 为剪切模量（单位 GPa），ν 为泊松比。

教材原文：在声学理论中，波速的倒数（1/v）称为慢度，在地球物理测井领域中则习惯称为声波时差，或简称为时差。

换算关系：时差 = 1000000 / 波速，时差用 μs/m，波速用 m/s。
